# Research experiments

Baselines: (1) fixed distance-threshold alerts, (2) CAPME weighted scoring.

Metrics: critical-hazard recall, false-alert rate, alerts/minute, end-to-end warning latency (ms), route-task completion under supervised protocols, and user-reported alert burden.

Freeze a labeled test set, log model/firmware versions, report uncertainty and failure cases. Do not report unmeasured improvements.
