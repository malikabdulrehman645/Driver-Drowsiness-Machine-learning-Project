# NOVA Android companion app — Kotlin

Create a **native Android Kotlin** project in Android Studio in this folder when ready (Empty Activity with Jetpack Compose recommended). Do not use Flutter.

Planned screens: Home/Connection, Destination Selection, User Preferences, Device Status.

Interfaces to agree with the Python team: selected destination ID, profile settings, connection state, and sensor/alert status. The app does not execute YOLO or CAPME in the proposed design.

**Why no generated Gradle project here?** Android Studio should generate version-compatible Gradle wrappers and SDK settings on the developer's machine. This avoids shipping a misleading or unbuildable project stub.
